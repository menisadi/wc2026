The Elo Rating Mechanism

A single number per nation that summarizes strength, updated match by match across the entire history of international football.

← Overview Poisson model Elo ratings

What Elo gives the engine

Elo is a self-correcting strength score. Beat a stronger team and you gain a lot; lose to a weaker one and you drop a lot. Over thousands of matches it converges to a stable ranking. In this project Elo plays two roles: it is a standalone baseline predictor, and — more importantly — it feeds the global strength features that the Poisson model relies on for cross-tier matchups.

Why self-compute it? The bundled Elo file only covers the 48 World Cup 2026 qualifiers. The engine instead replays results.csv from scratch to build ratings for all 321 teams, so no historical match gets dropped for a missing rating, and there are no name-matching gaps by construction.

The update formula

Walking matches in chronological order, after every game each team's rating moves by:

Rnew = Rold + K · G · (W − We)
TermWhat it is
Wactual result for the team: 1 win, 0.5 draw, 0 loss
Weexpected result — the win-probability implied by the rating gap
Kstep size: how much a single match can move the rating (depends on competition)
Ggoal-difference multiplier: blowouts move ratings more

Expected result (the logistic curve)

The rating gap is converted into a win expectation with the standard Elo logistic. The home (non-neutral) side gets a +100 rating bonus baked into the gap first:

dr = (Rhome + 100) − Raway   (the +100 is dropped at neutral venues)

We = 1 / ( 1 + 10−dr / 400 )

A 400-point edge means roughly a 10× higher implied odds of winning.

K — the competition weight

A World Cup result should shift perceptions more than a friendly. K is mapped from the match's tournament column (eloratings.net conventions):

CompetitionK
World Cup finals60
Continental finals (Euro, Copa, AFCON, Gold Cup, Nations League…)50
Qualifiers40
Other / default30
Friendlies20

G — the goal-difference multiplier

Winning 5–0 is stronger evidence than winning 1–0, so the update scales with the margin:

G = 1.0  if margin ≤ 1
G = 1.5  if margin = 2
G = (11 + N) / 8  if margin N ≥ 3

A worked example

Suppose home side A (1600) hosts B (1500) and wins 3–1 in a World Cup match:

Rating gap with home bonusdr = (1600 + 100) − 1500 = 200
Expected resultWe = 1/(1+10−200/400) ≈ 0.76
Actual result (win)W = 1
Margin = 2 → multiplierG = 1.5
K (World Cup)60
Δ = K · G · (W − We)≈ 60 · 1.5 · 0.24 ≈ +21.6
New ratingsA → 1621.6, B → 1478.4

The change is zero-sum: whatever A gains, B loses.

From a running rating to yearly snapshots

1
Start everyone at 1500. A new team's rating is seeded the first time it appears.
2
Replay history in date order (results from 1980 onward), applying the update after each match.
3
Record a year-end snapshot. The output is one row per (team, year) using the rating after that year's last match — columns country, year, rating.
4
Cache it. The history is written to data/elo_history_computed.csv and recomputed by refresh-data / snapshot whenever new results land.
The yearly schema is deliberately the same shape the Poisson model expects, so it can be consumed unchanged. The Poisson fitter looks up each match's rating by (team, year), falling back to nearby years to absorb snapshot gaps.

How Poisson uses these ratings

Two things flow into the Poisson model: the per-match historical Elo (standardized into scorer_elo_z / conceder_elo_z training features) and the latest rating per team (the predict-time strength used when a side has few or no training rows). Elo is also available on its own as the elo-only backtest baseline.
